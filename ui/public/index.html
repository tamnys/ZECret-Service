Trust boundaries

The public site is outside the private query path. The intended native path requires Tor, locally validated platform and workload evidence, and ownership of the live encryption key before query transmission. M0 does not implement that path.

No wallet keys, accounts, payments or transaction input are accepted here. Tor does not prevent all traffic correlation. Attestation is not proof of consensus, correct application code or deletion.

Site privacy

There are no analytics, remote assets or scripts. If published on GitHub Pages, GitHub records visitor IP addresses. Configuring CLI Tor does not anonymize this website or unrelated browser traffic.
